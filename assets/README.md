## Palette

| Name | Hex | Where |
| --- | --- | --- |
| Night (top) | `#17386a` | Icon field, gradient start |
| Night (bottom) | `#0a1a33` | Icon field, gradient end |
| Dawn | `#ffe7a8` | Ray tips |
| Sun | `#ffa62b` | Sun, accent rule, "OSS" in the wordmark |
| Page | `#ffffff`, `#dfe7f3` | Book pages |
| Ink | `#0f2547` | Wordmark on light backgrounds |

The wordmark is set in Inter, falling back to the system sans-serif.
Keep clear space of at least a quarter of the icon's width around it, and
never recolour or stretch the mark.
